How it works

Add the URL

Add a custom connector in Claude and paste the URL above.

Approve on Beeminder

Claude opens a sign-in window. You approve on beeminder.com, so your password never comes here.

Just ask

"Log 30 minutes of guitar", "what's about to derail?", "ratchet my reading goal to 2 days".

Setup

  1. Open Settings → Connectors and choose Add custom connector.
  2. Name it Beeminder and paste https://beemcp.dev/mcp. Leave the advanced settings alone.
  3. Click Connect, review the request, then approve on Beeminder.
  4. In a chat, enable the connector from the tools menu and ask about your goals.

Custom connectors are available on Claude's paid plans. On Team/Enterprise an owner may need to add it first.

Add the connector once on claude.ai or the desktop app (steps on the first tab). It then shows up in the Claude iOS and Android apps automatically.

claude mcp add --transport http beeminder https://beemcp.dev/mcp

Then run /mcp inside Claude Code and choose Authenticate.

Any client that supports remote MCP over Streamable HTTP with OAuth (Cursor, VS Code, MCP Inspector…) can use the URL directly. Older stdio-only clients can go through mcp-remote:

npx mcp-remote https://beemcp.dev/mcp

What Claude can do

list_goals

Every goal, most urgent first: buffer, bare minimum, derail time.

get_goal

One goal's details, with recent datapoints if you want them.

add_datapoint

Log progress, including backdating to an earlier day.

update_datapoint · delete_datapoint

Fix typos and mistakes.

list_datapoints

Browse a goal's history.

ratchet_goal

Cut a goal's safety buffer to keep yourself honest.

refresh_goal

Re-pull autodata goals such as fitness trackers.

get_user

Your timezone, deadline and goal list.

Privacy & FAQ

What do you store?

Nothing. There's no database. When you approve, Beeminder gives this server an access token. That token is encrypted (AES-256-GCM) into the token Claude keeps, and only this server can decrypt it, per request. Your Beeminder password never reaches this site.

How do I disconnect?

Remove the connector in Claude. To cut access completely, revoke the app in Beeminder under Account settings → Apps & API. Any token Claude still holds stops working right away.

Can it charge me money?

It can't change pledges or create new goals. Ratcheting and adding or deleting datapoints do affect whether a goal derails, so Claude is told to check with you before doing those.

Is this made by Beeminder?

No. It's an independent open-source project that uses Beeminder's public API and OAuth. The code is on GitHub, and you can host your own copy on Netlify in a few minutes.

Where's the source code?

github.com/stolati/beemcp. Read exactly what runs, open issues, or send pull requests.
